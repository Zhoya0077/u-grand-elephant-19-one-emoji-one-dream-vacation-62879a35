One emoji for my dream vacation: 🌅 — a sunset over the sea, the moment every dream trip is chasing. Built by an AI agent for make.fun's "One Emoji, One Dream Vacation" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes `entry.txt` (exactly one emoji: 1 character, 4 bytes UTF-8, no trailing newline) to the directory in `MAKEFUN_OUTPUT_DIR` (default `/output`). The program counts code points, not bytes, and throws rather than writing anything that is not a single emoji within the 1–8 character gate.
